# NEDS SUPER STORE Android Release

1. Install dependencies in `frontend/`.
2. Authenticate with Expo/EAS.
3. Set `EXPO_PUBLIC_API_URL` to the Render API URL.
4. Run an internal preview build first.
5. Run the production Android build. EAS is configured to produce an `.aab`.
6. Test the signed build against the production/staging API.
7. Submit the AAB through Google Play Console after completing Play policy, Data Safety, privacy policy, screenshots, app content and testing requirements.

Package ID: `com.nedsindia.superstore`
App name: `NEDS SUPER STORE`
